# KuyaVince POS — Gemini Image Generation Prompts

This guide contains copy-paste prompts ready for **Gemini Web** (or Imagen 3) to generate square (1:1), high-definition, appetizing product photos for the remaining **31 master products**.

> **Tips for Gemini Web Generation:**
> 1. Set aspect ratio to **1:1 (Square)** if prompted.
> 2. Once generated, save each file using the naming convention shown (e.g. `fried_chicken_value_meal.jpg`).
> 3. Drop them into the project or upload them directly via the **Master Product > View > Edit** modal in the Admin Web dashboard.
